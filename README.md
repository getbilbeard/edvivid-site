# EdVivid Site

Static site for `edvivid.com`, designed to be managed with GitHub Desktop and hosted with GitHub Pages.

## Open in GitHub Desktop

1. In GitHub Desktop, choose `File` -> `Add Local Repository`.
2. Select this folder.
3. Publish it to GitHub.

## Files

- `index.html`: landing page markup
- `styles.css`: site styling
- `CNAME`: custom domain for GitHub Pages

## DNS for GitHub Pages

When you are ready to move the live website away from GoDaddy Website Builder, update the apex domain and `www` records to GitHub Pages values.

Do not change those records until the repository is published and GitHub Pages is enabled.
